# سامانه کلینیک شنوایی آوینا

اطلاعات پرونده‌ها روی همان سروری که برنامه اجرا می‌شود ذخیره می‌شوند. این نسخه برای اجرا با Node.js و دیسک دائمی طراحی شده است و نباید روی محیط‌های بدون فایل‌سیستم دائمی مانند Cloudflare Workers اجرا شود.

## اجرا

نیازمندی: Node.js `>=22.13.0`

```bash
npm install
npm run dev
```

برنامه توسعه روی `http://localhost:5173` در دسترس است.

اجرای production:

```bash
npm run build
npm start
```

## محل اطلاعات

تمام اطلاعات قابل پشتیبان‌گیری زیر پوشه `data/` قرار دارند:

- `data/audiology.sqlite`: دیتابیس SQLite شامل تمام مقادیر پرونده‌ها و مشخصات فایل‌ها
- `data/images/`: تصاویر اصلی و علامت‌گذاری‌شده بیماران
- `data/pdfs/`: PDFهای بیماران

برای تغییر محل ذخیره‌سازی، متغیر `AUDIOLOGY_DATA_DIR` را روی یک مسیر مطلق در دیسک دائمی تنظیم کنید.

اطلاعات نسخه قبلی که در `localStorage` مرورگر بوده‌اند، هنگام اولین باز شدن برنامه به‌صورت خودکار به SQLite منتقل می‌شوند. تصاویر Base64 نیز به فایل واقعی تبدیل می‌شوند و پس از مهاجرت موفق، داده قدیمی مرورگر حذف می‌شود.

## بکاپ

ابتدا برنامه را متوقف کنید تا هنگام کپی هیچ پرونده‌ای در حال ذخیره شدن نباشد، سپس اجرا کنید:

```bash
npm run backup
```

یک کپی تاریخ‌دار از کل `data/` در `backups/` ساخته می‌شود. برای نگهداری خارج از سیستم، همان پوشه تاریخ‌دار را روی هارد یا فضای امن دیگری کپی کنید. محل خروجی را می‌توان با `AUDIOLOGY_BACKUP_DIR` تغییر داد.

برای بازیابی، برنامه را متوقف کنید، پوشه `data/` فعلی را کنار بگذارید و محتوای بکاپ موردنظر را جایگزین آن کنید.

- PDF: تا ۵۰ مگابایت
