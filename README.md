# سامانه کلینیک شنوایی آوینا

اطلاعات پرونده‌ها روی همان سروری که برنامه اجرا می‌شود ذخیره می‌شوند. این نسخه برای اجرا با Node.js و دیسک دائمی طراحی شده است و نباید روی محیط‌های بدون فایل‌سیستم دائمی مانند Cloudflare Workers اجرا شود.

## اجرای وب محلی

نیازمندی: Node.js `>=22.13.0`

```bash
npm install
npm run dev
```

برنامه توسعه روی `http://localhost:5173` در دسترس است.

اجرای production:

```bash
npm run build
npm start
```

## محل اطلاعات

تمام اطلاعات قابل پشتیبان‌گیری زیر پوشه `data/` قرار دارند:

- `data/audiology.sqlite`: دیتابیس SQLite شامل تمام مقادیر پرونده‌ها و مشخصات فایل‌ها
- `data/images/`: تصاویر اصلی و علامت‌گذاری‌شده بیماران
- `data/pdfs/`: PDFهای بیماران

برای تغییر محل ذخیره‌سازی، متغیر `AUDIOLOGY_DATA_DIR` را روی یک مسیر مطلق در دیسک دائمی تنظیم کنید.

اطلاعات نسخه قبلی که در `localStorage` مرورگر بوده‌اند، هنگام اولین باز شدن برنامه به‌صورت خودکار به SQLite منتقل می‌شوند. تصاویر Base64 نیز به فایل واقعی تبدیل می‌شوند و پس از مهاجرت موفق، داده قدیمی مرورگر حذف می‌شود.

## بکاپ

ابتدا برنامه را متوقف کنید تا هنگام کپی هیچ پرونده‌ای در حال ذخیره شدن نباشد، سپس اجرا کنید:

```bash
npm run backup
```

یک کپی تاریخ‌دار از کل `data/` در `backups/` ساخته می‌شود. برای نگهداری خارج از سیستم، همان پوشه تاریخ‌دار را روی هارد یا فضای امن دیگری کپی کنید. محل خروجی را می‌توان با `AUDIOLOGY_BACKUP_DIR` تغییر داد.

برای بازیابی، برنامه را متوقف کنید، پوشه `data/` فعلی را کنار بگذارید و محتوای بکاپ موردنظر را جایگزین آن کنید.

## محدودیت فایل

- تصاویر: JPEG، PNG یا WebP تا ۱۵ مگابایت
- PDF: تا ۵۰ مگابایت

## برنامه دسکتاپ

برنامه دسکتاپ Electron، سرور Next.js را فقط روی `127.0.0.1` اجرا می‌کند. دیتابیس و همه فایل‌های درمانی روی رایانه کلینیک می‌مانند. اجرای توسعه:

```bash
cp .env.desktop.example .env.local
npm run desktop:dev
```

ساخت بسته محلی و بسته انتشار:

```bash
npm run desktop:pack
npm run desktop:dist
```

پیش از انتشار، آدرس سرور مجوز و کلید عمومی Ed25519 را از طریق متغیرهای `AUDIOLOGY_LICENSE_SERVER_URL` و `AUDIOLOGY_LICENSE_PUBLIC_KEY` تنظیم کنید. بسته‌های ویندوز و macOS باید با گواهی سازمان امضا شوند. آدرس آزمایشی `updates.example.invalid` در `package.json` نیز باید با مخزن HTTPS واقعی به‌روزرسانی جایگزین شود.

صفحه تنظیمات دسکتاپ امکان انتخاب و انتقال امن پوشه اطلاعات، انتخاب سربرگ، پشتیبان‌گیری و بررسی به‌روزرسانی را فراهم می‌کند. اطلاعات فعال‌سازی در پوشه داده درمانی ذخیره نمی‌شود.

## سرور مجوز

سرور مرکزی فقط حساب‌ها، دستگاه‌ها، مجوزها و نسخه‌های انتشار را نگهداری می‌کند و هیچ اطلاعات بیمار را دریافت نمی‌کند. راه‌اندازی آن در [server/README.md](server/README.md) توضیح داده شده است.

اجرای Docker روی سرور:

```bash
./scripts/init-server-secrets.sh
docker compose -f compose.server.yml up -d --build
curl http://127.0.0.1:8787/health
```

پورت سرویس فقط روی loopback سرور منتشر می‌شود و باید با Nginx/Caddy و HTTPS در اینترنت ارائه شود. PostgreSQL داخل شبکه خصوصی Compose قرار دارد.

مجوز آفلاین این پیاده‌سازی با کلید موجود در keystore سیستم‌عامل مهروموم می‌شود. برای الزام سخت‌افزاری TPM/Secure Enclave در محیط نهایی، provider بومی سازمان باید جایگزین provider `os-keystore` شود؛ دستگاه‌های فاقد provider سخت‌افزاری نباید مجوز آفلاین production دریافت کنند.
